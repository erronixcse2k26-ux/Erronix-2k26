ABOUT THE EVENT

AI Prompt War is a prompt-based website creation challenge where participants use AI to build functional websites from given problem statements.

Participants must create their own prompts during the event and complete the required website within the specified time and prompt limits.

RULES & REGULATIONS

01
Each participant must create one complete and functional website using AI.
02
Each participant is allowed a maximum of 5 AI prompt attempts throughout the competition.
03
Prompts must be created during the competition. Pre-written or copied prompts are not allowed.
04
The completed website must be submitted within the given time limit.
05
Judges may test the functionality of the submitted website through a live demonstration.
