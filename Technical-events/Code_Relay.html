ABOUT THE EVENT

Code Relay tests not only individual coding prowess, but how seamlessly you read, comprehend, and push forward your partner's code without exchanging a single word.

In this competitive programming relay, pairs must solve algorithmic problems by alternating turns on a single machine at timed buzzer intervals. Member 1 lays the architecture and logic; upon the relay signal, Member 2 steps in to review the code structure, fix defects, and complete edge cases to pass all automated test suites.

Supported Programming Languages

C C++ (GCC) Java (OpenJDK) Python 3

RULES & REGULATIONS

01
Team Size: Exactly 2 members per team. Advance online registration is mandatory; entries are on a first-come, first-served basis.
02
Language Selection: Allowed programming languages are C, C++, Java, and Python. Both teammates must write in the same chosen language.
03
Relay Swap Protocol: Teammates must swap places only at the designated buzzer/time interval. When one member is coding, the other must stand behind the designated boundary.
04
Zero Verbal Communication: STRICT No talking, whispering, hand gesturing, or note-passing is permitted during the relay handover.
05
Fair Play & Original Code: Only original code solutions generated in the session are accepted. Any unauthorized devices, tab switching, or external assistance results in immediate disqualification.
06
Evaluation Criteria:
  • Correctness and total number of passed automated test cases.
  • Overall submission speed and elapsed time.
  • Code modularity, algorithmic complexity, and structure.
