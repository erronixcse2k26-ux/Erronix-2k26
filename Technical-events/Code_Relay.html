Code Relay

About the Event

A collaborative coding challenge where teammates take turns solving, debugging and completing a programming problem under time constraints. Code Relay tests teamwork, code comprehension, logical continuity, and rapid problem-solving under competitive pressure.

Event Schedule

  • Date: October 2026
  • Time: 11.00 AM to 1.00 PM
  • Venue: Computer Science Laboratory

Category & Participation

  • Category/Theme: Competitive Programming & Relay Debugging
  • Participation: Teams of 2 (First-come-first-serve)

Registration & Prerequisites

  • Registration Process: Online / First-come, first-served (No on-spot registration).
  • Registration Deadline: Advance Online Registration Mandatory
  • Prerequisite: Valid college ID card for verification

Event Rules & Guidelines

General Rules:

  • Must carry a valid college ID card for campus entry and verification.
  • Only original code solutions allowed; any malpractice or cheating will lead to immediate disqualification.
  • Judges’ decisions are final and binding.
  • Maintain laboratory decorum throughout the event.

Relay Format Rules:

  • Supported Languages: C, C++, Java, Python.
  • Teammates swap places at fixed time intervals to continue code written by their partner.
  • No verbal communication or whispering is permitted during relay handovers.
  • Participants must understand their teammate's code logic quickly and push the solution forward.
  • The final solution must successfully pass all automated test cases within the allotted time limit.

Evaluation Criteria:

  • Correctness and test case coverage.
  • Execution speed and submission time.
  • Code modularity, logic quality, and algorithmic efficiency.

Event Flow & Time Allocation

  • Coding & Relay Time: 45–60 minutes
  • Evaluation & Review: 15 minutes
  • Format: Fast-paced elimination / timed problem sets

Rewards & Recognition

  • All participants will receive a Participation Certificate.
  • Winners and Runners-up will be awarded special prizes in recognition of their outstanding performance.

Code of Conduct

  • Be punctual and arrive 10 minutes before the event.
  • Follow instructions given by coordinators.
  • Any misbehaviour, cheating, or violation of rules will lead to disqualification.
